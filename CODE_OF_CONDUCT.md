# Código de Conduta

Este projeto adota o [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/),
versão 2.1.

## Resumo

- Trate todo mundo com respeito e empatia — pessoas iniciantes são o
  público-alvo deste plugin, e a mesma postura vale para as issues.
- Críticas são sobre código e ideias, nunca sobre pessoas.
- Não são tolerados assédio, ataques pessoais, linguagem depreciativa ou
  divulgação de informações privadas de terceiros.

## Aplicação

Comportamentos abusivos podem ser reportados abrindo uma issue ou contatando
o mantenedor pelo e-mail do perfil do GitHub. Denúncias são tratadas com
confidencialidade. O mantenedor pode remover comentários, commits e
contribuições que violem este código, e banir temporária ou permanentemente
quem reincidir.
